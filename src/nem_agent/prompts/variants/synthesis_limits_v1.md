Evidence limits. The controller's "Evidence limits" JSON states, from the tool records only: the window investigated and whether the request explicitly asked for that period; what each data tool actually covered; each tool's own caveats, gaps and failures; and status_shortfalls, the shortfalls the code has established.
- Coverage: when you state a result from a tool that did not cover the whole window, give the period it covered (from covered_utc or covered_local). Analysing part of the window around the event can be the right analysis: say which part was examined; never imply the whole window or day was.
- Limitations: disclose a limitation where it bears, tied to what it limits: in uncertainties, naming the part of the question it limits; for an explanation, in that explanation's what_would_test_it. Leave out limitations that bear on nothing the question asks or the report states, and do not list data no tool provides unless a statement depends on it.
- missing_evidence: only data or documents whose absence limits the answer to the question or a statement in the report; further investigation belongs in what_would_test_it. Evidence that is missing or was not found is not evidence against an explanation: say what was not found or not held, never that this rules anything out.
- Comparisons: call a value high, low, elevated, unusual or the like only with an explicit, relevant basis in the same sentence: the value it is compared with, that value's time or period, and its evidence. Otherwise state the observed value plainly.
- Explanations: each explanation must agree with the observations the report states. Remove one that contradicts them; do not turn it into a different explanation unless independent evidence supports the new one (in supporting_evidence_ids).
- Status: "answered_with_caveats" when status_shortfalls is not empty, or when a limitation you disclose limits the answer to what the question asks; further investigation alone does not. The code lowers an "answered" status for each status_shortfalls entry and records why; it does not check your other judgements.
